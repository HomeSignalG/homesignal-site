## What a treatment result means

IndexNow's HTTP 200 means the endpoint **received** the list. It does not mean any page was
crawled or indexed.

For **Bing**, the treatment arm differs from the control in **two** ways: the page content
(records in the first HTML) and a fresh IndexNow notification (plus a moved sitemap lastmod).
The controls got neither. A Bing difference therefore measures both effects together, and this
design cannot separate them.

**Google** does not use IndexNow. For Google the only extra signal is the moved sitemap
lastmod, read whenever Google reads the sitemap.

**Shared changes.** No change-detection code was changed (`page_semantics.py`, `indexnow.py`
untouched). The only shared edits are the runtime script and two CSS rules in
`homesignalmap.html`. Neither is fingerprinted, so neither moved a control's lastmod or
reached IndexNow, which the 100 unchanged control lastmods confirm.

makes after it renders, and the ZIP is in the POST body, which is not logged. Requests for the
